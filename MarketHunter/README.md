# MarketHunter — APK Android de validation (19 octobre 2026)

Deux applications indépendantes pour Android :

- MarketHunter Vente : créer des brouillons, associer une photo, partager une annonce, marquer vendu.
- MarketHunter Business : rechercher chez plusieurs marchands via les sites publics, recevoir un lien partagé, calculer une marge manuelle et consulter les tendances publiques Google France. Les données de tendances ne sont **pas** des preuves de ventes.

Ces APK ont compilé localement avec Android Gradle et leur signature v2 a été vérifiée. La dernière révision n'a **pas** été testée sur Motorola : ADB indisponible au moment du contrôle. Ce sont des versions personnelles de validation, pas des livraisons commerciales définitives. Elles n'achètent pas, ne publient pas automatiquement et ne possèdent pas l'accès API eBay/Amazon/Facebook tant que les autorisations correspondantes ne sont pas en place.
